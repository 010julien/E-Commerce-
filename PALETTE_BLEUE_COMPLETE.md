## 🎨 Utilisation des Couleurs

### Importer la configuration
```javascript
import colors from '../styles/colors';

// Utilisation
<div style={{ backgroundColor: colors.primary }}>
```

### Classes Tailwind directes
```javascript
// Bouton principal
<button className="bg-[#1b9abe] hover:bg-[#139cbc] text-white">

// Texte
<p className="text-[#1b9abe]">

// Bordure
<div className="border border-[#9dd5e1]">
```

### Style inline avec hover
```javascript
<button
  style={{ backgroundColor: '#1b9abe' }}
  onMouseEnter={(e) => e.currentTarget.style.backgroundColor = '#139cbc'}
  onMouseLeave={(e) => e.currentTarget.style.backgroundColor = '#1b9abe'}
>
  Hover me
</button>
```
